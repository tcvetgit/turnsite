## 3. Приём заявок (Telegram/Почта)

Заявки с формы попадают на `functions/api/lead.js`. Она отправляет уведомления в Telegram и на почту.

**Настройка Telegram-уведомлений:**
1. Создайте бота через `@BotFather` (`/newbot`), получите токен.
2. Напишите боту `/start` со своего аккаунта.
3. Узнайте `chat_id` через URL: `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → найдите `message.chat.id`.
4. В Cloudflare Pages (или другом хостинге функций) задайте секреты:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

**Настройка почтовых уведомлений (Resend):**
1. Зарегистрируйтесь на Resend, подтвердите домен (SPF/DKIM).
2. Создайте API key.
3. В секретах хостинга задайте:
   - `RESEND_API_KEY`
   - `LEADS_EMAIL` (получатель, например `Turnov-Sergeevich@yandex.ru`)
   - `LEADS_FROM` (адрес отправителя на подтверждённом домене)

## 4. Публикация

Сайт рассчитан на Cloudflare Pages (папка `cmpl` как Root Directory). Функция `functions/api/lead.js` работает только там. Для другой платформы адаптируйте endpoint.

1. Загрузите содержимое папки `cmpl` на хостинг.
2. Укажите Root Directory = `cmpl`.
3. Deploy. Проверьте, что `GET /api/lead` возвращает `405` (функция обнаружена).

## 5. SEO-настройка

В `sitemap.xml` и `robots.txt` замените `ВАШ-ДОМЕН` на реальный адрес сайта.
